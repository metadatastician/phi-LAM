= phi-LAM
:toc:

phi-LAM is a pre-alpha research seed for describing and normalising small,
typed action sequences.

The repository currently contains one deliberately narrow Idris 2 component:
an explicit rewrite rule that removes adjacent duplicate `EvaluateLLM` actions
and returns both the normal form and a derivation trace. That component is the
whole implemented scope. It is not yet an agent architecture, a runtime, a
sandbox, an inference engine, or a Kautz-graph implementation.

== Evidence-backed example

The checked implementation maps:

[source]
----
[ReadMemory, EvaluateLLM, EvaluateLLM, CallSandbox]
----

to:

[source]
----
[ReadMemory, EvaluateLLM, CallSandbox]
----

with a trace identifying the application of `PruneRedundantEvaluation` at
input position `2` (zero based).

== Build and test

The currently checked toolchain is Idris 2 0.7.0.

[source,sh]
----
idris2 --build phi-lam.ipkg
idris2 --source-dir src -o phi-lam-tests src/TestNormalize.idr
./build/exec/phi-lam-tests
----

If `just` is installed, `just check` performs all three steps.
