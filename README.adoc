= phi-LAM
:toc:

phi-LAM is a pre-alpha research seed for describing and normalising small,
typed action sequences.

The repository currently contains a deliberately narrow Idris 2 semantic
kernel and pure reference scheduler. The normalizer removes adjacent scheduler
entries only when they carry the same request identity and the `AtMostOnce`
policy, returning both the normal form and a type-aligned derivation. The
reference scheduler gives that policy executable meaning: the first request
changes effective state and later attempts with the same identity are
suppressed. This is not yet an agent architecture, an external scheduler
adapter, a sandbox, an inference engine, or a Kautz-graph implementation.

== Evidence-backed example

The checked implementation maps:

[source]
----
[ ReadMemory
, ScheduleEvaluation(request-0, AtMostOnce)
, ScheduleEvaluation(request-0, AtMostOnce)
, CallSandbox
]
----

to:

[source]
----
[ ReadMemory
, ScheduleEvaluation(request-0, AtMostOnce)
, CallSandbox
]
----

with a trace identifying the application of `PruneRedundantEvaluation` at
input position `2` (zero based).

== Checked guarantees

The Idris types and total proofs establish that:

* every derivation step transforms its indexed input into its indexed output;
* only the second of two identical adjacent `AtMostOnce` requests can be
  removed;
* requests with different identities, `Repeatable` requests, and mixed
  policies are retained;
* the result contains no pair carrying redundancy evidence;
* normalization cannot invent or reorder retained actions; and
* normalization is idempotent; and
* normalization preserves interpretation for every scheduler model that proves
  its at-most-once operation idempotent.

`PhiLam.ReferenceScheduler` discharges that model obligation for a concrete,
pure state transition. Its checked theorem proves that scheduling the same
`AtMostOnce` identity twice has exactly the effective state of scheduling it
once. `execute` reports suppressed duplicate attempts as diagnostics kept
separate from effective semantics; normalization is not claimed to preserve
those diagnostic lists.

An independent Lean 4 formalization in `formal/lean/` reconstructs the action
calculus rather than importing generated Idris output. It proves that the Lean
normalizer produces a normal form, normal forms are fixed points,
normalization is idempotent, normalization constructs a valid rewrite
derivation, and every such derivation preserves every lawful scheduler model.
Shared examples check agreement on the documented rule boundary. This is
independent theorem-prover corroboration, not a formal compiler-to-compiler
equivalence theorem.

The audit trace is an erased runtime view of the typed derivation. Positions
refer to the sequence as it exists when each rewrite is applied, not to stale
positions in the original input.

== Build and test

The currently checked toolchain is Idris 2 0.7.0.

[source,sh]
----
idris2 --build phi-lam.ipkg
idris2 --source-dir src -o phi-lam-tests src/TestNormalize.idr
./build/exec/phi-lam-tests
cd formal/lean && lake build
----

If `just` is installed, `just check` performs all three steps.
