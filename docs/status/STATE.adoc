:date: 2026-08-01

This ledger distinguishes intentions from evidence. Status terms are:
`hypothesis`, `specified`, `sketched`, `implemented`, `integrated`, `tested`,
`verified`, and `operational`.

[cols="2,1,4",options="header"]
|===
|Claim |Status |Evidence or limitation

|Closed action vocabulary
|implemented
|`src/PhiLam/Action.idr` defines the three currently supported actions.

|Adjacent evaluation normalisation
|verified
|`src/PhiLam/Normalize.idr` is total and returns a `NormalForm` certificate;
`normalizedIsNormal` connects that certificate to the executable predicate.

|Derivation trace
|verified
|`RewriteEvidence before after` and `Derivation before after` align every
rewrite by type. `audit` erases that evidence to named dynamic positions.

|Idempotence
|verified

|verified

input sequence.

state or prove observational preservation.

through five for normality, idempotence, and trace/removal accounting. These
