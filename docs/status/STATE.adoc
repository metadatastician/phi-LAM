`hypothesis`, `specified`, `sketched`, `implemented`, `integrated`, `tested`,
`verified`, and `operational`.

The executable suite also exhaustively checks all 781 sequences of length zero
through four over a five-action vocabulary for normality, idempotence,
trace/removal accounting, and agreement with a concrete lawful test model. It
also checks negative cases for different request identities, repeatable
requests, and mixed policies. These bounded tests supplement the general
proofs; they are not their foundation.
